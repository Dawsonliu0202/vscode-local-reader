# VS Code 本地阅读插件：功能描述 PRD

版本：v0.5.0（目录搜索、正文快速排版与窄栏布局）

日期：2026-10-30

状态：用户已确认，首版已按此范围实现（验证情况见 VERIFICATION.md）  
配套文档：[实现方案](./IMPLEMENTATION_PLAN.md)

## 1. 产品目标与首版边界

在 VS Code 内导入、管理和阅读本地电子书，自动保存阅读位置和有效阅读时长，并提供融入编辑器界面的低干扰阅读方式。

首版完成一个闭环：**导入书籍 → 书架管理 → 选择外观阅读 → 随时隐藏 → 恢复位置 → 查看记录和时长**。

| 项目 | 首版约定 |
| --- | --- |
| 使用环境 | VS Code 桌面版，优先在 Windows 本地环境验收；无需打开项目文件夹 |
| 书籍格式 | TXT，以及无 DRM 的 EPUB 2/3 文字类书籍 |
| EPUB 展示 | 提取正文、段落、标题和目录；使用插件统一排版 |
| 阅读外观 | 侧边栏、文件标签页、底部原生终端 + 阅读分栏 |
| 数据范围 | 本机同一 VS Code 用户环境内，切换工作区保留书架和记录 |
| 联网需求 | 阅读、管理、统计均离线运行 |
| 交付方式 | 源码、可本地安装的 VSIX、简要使用说明 |

**本版不包含**：PDF、MOBI、AZW、扫描书 OCR、DRM 解密、EPUB 原版式与插图还原、在线书城、账号与云同步、AI、批注与划线、复杂标签分类、阅读目标、自动翻页、插件市场发布。用户提出的“等格式”先收敛为 EPUB/TXT，后续格式需单独确认。

## 2. 核心使用场景

1. 用户选择一本本地 TXT 或 EPUB，导入后在书架看到书名和进度，点击即可阅读。
2. 用户通过快捷键打开最近阅读的书，使用左右按钮或方向键翻页，退出后自动保存位置。
3. 用户根据当前界面切换侧边栏、文件页或底部面板，继续阅读相同内容。
4. 用户按一次隐藏快捷键或点击隐藏按钮，正文、书名和统计信息从插件界面消失；再次主动打开后恢复。
5. 用户查看今日、最近 7 天、累计阅读时长，以及每本书的阅读记录。

## 3. 功能需求

以下均为首版必须功能，不另设扩展功能清单。

### 3.1 本地导入

| 编号 | 功能 | 规则 |
| --- | --- | --- |
| F01 | 选择文件 | 通过系统文件选择框导入，支持一次选择多个 EPUB/TXT，逐本处理 |
| F02 | 保存副本 | 将书籍复制到插件专用本地目录；用户移动或删除原文件后仍能阅读 |
| F03 | 提取信息 | EPUB 优先读取书名、作者和目录；缺失书名时使用文件名；TXT 默认使用文件名 |
| F04 | TXT 编码 | 支持 UTF-8、GBK/GB18030；优先识别 UTF-8，回退时展示预览并允许手选编码 |
| F05 | 重复处理 | 按文件内容判断重复；完全相同文件不重复入库，直接定位已有书籍；同名不同内容可共存 |
| F06 | 导入失败 | 显示明确原因，如损坏、加密、无可读正文、权限不足或超过限制；失败不产生无效书架条目 |

单文件上限暂定 **50 MiB**；导入显示进度并允许取消。批量导入时，一本失败不影响其他书籍。对同一本已导入 TXT，编码在入库前确认；首版不提供入库后的重新解码功能。

### 3.2 书架管理

- 采用紧凑列表，显示书名、作者（存在时）、格式、当前进度和最近阅读时间，不制作封面墙。
- 提供按书名关键词筛选，默认按最近阅读排序；未读书籍按导入时间排序。
- 支持开始阅读、继续阅读、修改显示书名、移除书籍。
- 阅读状态由进度推导为“未读 / 阅读中 / 已读完”，不增加手工状态管理。
- 移除前确认：删除插件中的书籍副本、正文缓存、进度和该书阅读记录；**不删除用户原文件**。该书时长也从统计中移除，确认提示中说明这一点。
- “导入书籍”按钮只在书架页面展示，空书架同样使用该入口。
- 左侧活动栏增加书本图标，点击直接进入侧栏书架管理；原有资源管理器侧栏阅读入口保留。

### 3.3 基础阅读

- 默认继续上次阅读；首次打开从正文开头开始。
- 支持上一页 / 下一页、上一章 / 下一章、目录跳转；正文禁用滚轮、上下方向键、PageUp/PageDown 和空格翻页。
- 点击正文左侧三分之一上一页，右侧三分之一区域下一页；中间区域不翻页。拖动选字和清除已有选区不翻页，菜单或目录打开时不触发背景翻页；三种模式一致。
- EPUB 优先使用书内目录，缺失目录时按正文文档顺序生成列表。TXT 识别常见“第 X 章”等章节标题；识别失败时按正文分段阅读，不要求用户手动整理。
- 打开目录时自动滚动到并高亮当前阅读章节；长目录尽量居中，切章或目录跳转后再次打开同步更新。按正文锚点匹配，不能仅按章名或正文存储分块匹配。
- 目录顶部固定标题、搜索框及操作，支持按章节名 / 章号筛选，仅列表滚动；↑/↓ 选择、Enter 跳转、Esc 关闭并返回正文，组合输入选字不得触发跳转。无结果时提示并可清空，“回到当前章”清空筛选并定位阅读项；筛选后沿用原始锚点。
- 字体族跟随 VS Code 默认界面字体，字号默认跟随编辑器；允许调整字号、行高，颜色跟随当前 VS Code 主题。
- 独立阅读设置页提供字号跟随开关、自定义 8–40 px 字号、1.2–3.0 倍行高、实时文字预览、保存、恢复默认及保存并继续阅读。
- 正文 ⚙ 打开快速排版浮层，在实际正文中预览字号与行高并保持稳定正文位置；应用才写入现有配置，取消 / Esc 恢复原排版与位置，隐藏、切书和离开阅读界面时清理未应用状态。浮层提供完整设置入口，操作不触发正文分区翻页。
- 底部模式默认左侧 Terminal、右侧 Reader；阅读设置允许对调左右并持久化。只调整位置，不清空终端输入、不结束终端进程。
- 默认使用侧边栏模式；用户选择其他模式后记住上次选择。
- 同一窗口只展示一本书、一个阅读载体；切换模式时收起旧载体并保留位置，防止正文同时出现在多个区域。
- 章节名与书名上下显示，与两侧按钮共用一排紧凑工具栏，按整个阅读区域居中，长文本省略并保留悬浮全文；移除阅读视图原生标题栏与正文重复的插件操作。窄栏优先保留上一页、下一页、目录、隐藏和 ⋯，切章与快速排版收进菜单，宽栏自动展开，原有快捷操作保留。底部显示本章当前页及总页数。页码随区域大小和排版变化，不作为持久化位置。
- 设置页只保留排版、底部分栏、预览及保存/恢复操作，删除重复说明。
- 打开书架或统计页面时暂停正文阅读与计时；返回阅读后从原位置继续。

### 3.4 阅读记录与进度

**位置规则**

- 保存正文中的稳定位置，不保存固定页码或屏幕像素滚动值。
- 翻页、章节切换、目录跳转后保存；切书、切换模式、隐藏、关闭阅读器时再次保存。
- 重启 VS Code 后由用户主动打开阅读器，再恢复书籍和位置；不自动展示正文。
- 调整字号、面板宽度或阅读模式后，恢复到相同正文位置，允许显示换行发生变化。

**进度口径**

- 当前进度 = 当前正文位置之前的文本长度 ÷ 全书规范化正文长度。
- 到达最后一段末尾时显示 100%；未打开过的书显示 0%。
- 这是当前所在位置，回翻会降低百分比，不计算“已读覆盖率”。
- 进度不受窗口尺寸和字号影响；“已读完”由到达正文末尾推导。

**阅读记录**

- 原始会话按打开至结束保存；列表按“同一本书、同一天”合并，原始数据与累计时长保留。
- 每条只显示书名、日期、当天累计时长和可确定的首末进度，去掉重复的完整时间戳；跨日会话没有逐日位置快照时省略进度范围。
- 窗口失焦、阅读区域暂时不可见或空闲只暂停计时。
- 支持按书籍筛选，按最近阅读日期倒序显示。

### 3.5 阅读时长分析

首版只展示四类信息：

| 指标 | 展示方式 |
| --- | --- |
| 今日阅读时长 | 汇总数字，不足一分钟显示秒数 |
| 最近 7 天阅读时长 | 逐日简单柱状图，包含今天和前 6 天 |
| 累计阅读时长 | 全部仍在书架中的书籍有效时长之和 |
| 单书阅读时长 | 书籍列表中的累计时长及该书阅读记录 |

**有效时长必须同时满足**：

1. 正文已经展示，阅读器未处于隐藏状态；书架和统计页面不计时。
2. VS Code 窗口处于前台且阅读区域可见；正文可见时不要求键盘焦点一直停在正文。
3. 距离最近一次正文操作未超过 **120 秒**。翻页、切章、目录跳转或在正文内点击可更新活跃时间；单纯移动鼠标或滚轮不更新。

超过 120 秒后停止累计，从下一次正文操作重新开始，不补计空闲时间。打开正文视为一次操作，因此长时间停留在一屏最多计入 120 秒。这是近似阅读时间，不是注意力检测。

内部按秒统计，按时长换算小时、分钟或秒展示；按用户系统本地日期归属，跨午夜的有效时长拆到对应日期。正常结束立即保存，异常退出最多允许丢失最近 **15 秒**尚未持久化的数据。

### 3.6 三种阅读外观

| 模式 | 用户看到的形式 | 首版实现边界 |
| --- | --- | --- |
| 侧边栏 | 资源管理器中的中性命名视图 `Workspace Notes`，窄栏显示正文 | 独立扩展视图，不修改实际文件树；书架通过显式入口打开 |
| 文件页面 | 中性标题 `notes.log` 的编辑器标签，正文跟随 VS Code 默认界面字体 | 这是插件阅读标签，不创建真实项目文件，不支持编辑或保存正文 |
| 底部终端分栏 | 原生 `Terminal` 标签内，左侧是真实终端，右侧 `Task Output` 阅读面板 | 原生终端正常输入与执行命令；只移动插件阅读视图，不接管终端进程；分隔条可拖动 |

三种模式共用同一套正文、进度和操作。首版只提供这三套固定外观，不提供自定义皮肤或伪造代码生成器。

**隐蔽性边界**：提供中性容器名称与快速隐藏；本轮按用户要求在顶部显示书名与章节。正文仍是可见文字；扩展列表、本地数据和 VS Code 自身记录可能暴露插件用途，不承诺系统级隐藏或“无痕”。

### 3.7 快捷键与鼠标操作

以下是建议默认键位，最终可在 VS Code 快捷键设置中修改；macOS 使用对应的 `Cmd` / `Option` 组合，正式兼容性以后续实测为准。

| 操作 | 建议快捷键 | 鼠标入口 | 生效范围 |
| --- | --- | --- | --- |
| 打开 / 继续最近书籍 | `Ctrl+Alt+R` | 命令或视图菜单 | VS Code 内；无书籍则打开书架 |
| 隐藏全部插件内容 | `Ctrl+Alt+H` | 阅读界面固定的中性隐藏按钮 | 插件正在显示正文、书架或统计时 |
| 快速隐藏 | `Esc` | 同上 | 仅正文获得焦点且无内部弹层时 |
| 上一页 / 下一页 | `Left` / `Right` | 顶部 `‹` / `›` 按钮 | 正文获得焦点时 |
| 上一章 / 下一章 | `Alt+Left` / `Alt+Right` | 顶部 `«` / `»` 按钮，或目录 | 正文获得焦点且未在输入控件中时 |
| 切换模式 | 不预占额外默认键 | 中性模式菜单 | 阅读器内 |
| 书架、导入、记录与统计 | 不预占额外默认键 | 显式管理菜单、书架按钮 | 插件管理界面 |

所有操作都可通过命令面板触发。普通翻页键不在代码编辑器或真实终端输入时生效；插件无法提供 VS Code 失去焦点后的系统全局快捷键。

**隐藏行为**：立即清除所有插件视图中的正文、书名、目录、记录与统计；关闭自身阅读编辑器标签，移除底部阅读分栏并收起活动栏书架，其余扩展视图显示中性占位。停止计时，保存位置；不关闭用户的代码文件或真实终端。再次阅读必须由用户主动触发。

## 4. 异常与数据处理

| 情况 | 预期行为 |
| --- | --- |
| EPUB 受保护、损坏或没有可读文字 | 导入失败，说明原因 |
| TXT 预览乱码 | 入库前切换编码；无法解码则取消导入 |
| 导入取消、磁盘不足或写入失败 | 清理本次临时数据，已存在书籍不受影响 |
| 原始文件移动或删除 | 继续使用已导入副本 |
| 正文缓存丢失 | 从导入副本重建；副本也缺失时提示重新导入 |
| 状态文件异常 | 尝试读取上一份完整备份；失败时提示，不静默清空书架 |
| VS Code 崩溃或强制退出 | 恢复最近保存点；不把离线期间算为阅读时间 |

不向项目目录写入书籍或阅读记录，不上传正文或使用情况，不默认开启遥测。不同 VS Code 安装、用户环境及远程环境之间不承诺共享书库。

## 5. 首版验收标准

| 编号 | 验收项 | 通过标准 |
| --- | --- | --- |
| A01 | 导入 | UTF-8 TXT、GB18030 TXT、普通 EPUB 2/3 可入库；相同文件重复导入不增加条目 |
| A02 | 失败隔离 | 损坏文件、加密文件、超限文件或取消导入均不留下可见的半成品书籍 |
| A03 | 书架 | 可筛选、改名、移除、继续阅读；移除不影响原文件 |
| A04 | 三种模式 | 均能鼠标和键盘阅读；切换后显示相同正文位置，旧载体不继续显示正文 |
| A05 | 进度恢复 | 翻页、改字号、调整宽度、切模式及重启后，恢复同一正文位置；末尾显示 100% |
| A06 | 快速隐藏 | 快捷键及鼠标均可隐藏全部插件内容，停止计时，代码文件和真实终端保留 |
| A07 | 按键范围 | 阅读器外的翻页、导航和终端输入不被插件普通阅读按键拦截 |
| A08 | 时长口径 | 前台可见时累计；隐藏、切走窗口、超过 120 秒无正文操作后不累计；切模式不重复计时 |
| A09 | 统计一致 | 今日、7 天、累计及单书时长与阅读记录一致；跨日记录正确拆分 |
| A10 | 离线与恢复 | 断网可完成核心流程；移动原文件仍可读；异常退出后不补计离线时间 |

交互目标：常用测试书籍再次打开不超过 1 秒；隐藏视觉响应不超过 200 毫秒。导入 10 MiB 以内文字书籍目标不超过 5 秒，处理过程不持续阻塞编辑器交互。这些是编码后的验收目标，目前尚无性能测试结果。

## 6. 本次确认内容

确认本 PRD，代表确认以下首版取舍：

1. 优先 Windows 本地桌面环境，先支持 TXT 与 EPUB 文字阅读。
2. 三种阅读外观保留；按用户追加需求，底部模式升级为真实终端与阅读面板分栏，文件页仍采用插件标签页。
3. 使用本地书籍副本和本地记录；不增加账号、联网与复杂书架系统。
4. 时长采用“前台可见 + 120 秒内有正文操作”的近似口径。

本需求已由用户确认并授权完整编码。首版实现和验证结果见 [验收记录](./VERIFICATION.md)。
