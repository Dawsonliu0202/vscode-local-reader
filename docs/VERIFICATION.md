TypeScript、17 项核心测试、VS Code 宿主集成测试和 VSIX 打包通过。已读取包内清单确认 `Dawson.local-reader@0.5.1`、PNG 图标路径与 256×256 尺寸；128×128 发布者 Logo 另行导出。证据为 `.test-data/core-marketplace-v051.log`、`host-marketplace-v051.log` 和 `package-marketplace-v051.log`。因没有修改阅读界面，本轮未重复 v0.5.0 已通过的四组浏览器测试。

## 性能样本

使用 `npx tsx scripts/benchmark.ts` 在本机测得：

| 样本 | 结果 |
| --- | --- |
| 合成中文 TXT | 10,485,670 字节，225 个正文块 |
| 副本、哈希、解析、缓存和书架提交 | 142 ms |
| 已导入正文缓存读取与解析 | 45 ms |

这是单次合成样本的数据路径测量，不代表所有 EPUB、所有机器，也不包含 VS Code 完整绘制耗时。隐藏的 DOM 清屏和集成行为已验证，200 ms 端到端视觉响应目标尚未进行精密测量。

## 待人工复核与范围限制

- 原生桌面工具报 `window id … no longer belongs to Microsoft.VisualStudioCode; current owner is Microsoft.VisualStudioCode`，已通过上文的 Electron 工作台事件注入完成快捷键和输入隔离验证。各系统输入法的候选窗及用户自定义键位 / 终端路由仍建议人工复核；组合输入保护已做事件级自动测试。
