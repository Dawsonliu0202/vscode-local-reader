# 实现与验收记录

日期：2026-10-29；版本：0.4.1。

已交付源码、安装用 VSIX、使用说明和自动化测试。0.4 合并阅读记录，精简管理与设置界面，改为左右分页、独立章节按钮和顶部书名/章节、底部本章页码。字体族跟随 VS Code 默认界面字体。书籍和阅读数据格式与旧版兼容，原始会话保留。

0.4.1 增加正文左右分区点击：左右各三分之一分别上一页、下一页，中间区域不翻页。真实浏览器鼠标事件验证了三种模式、正文文字与空白点击、单次翻页、首章起点和跨章衔接；拖动选字、拖动空白、清除已有选区及打开菜单时的背景点击均不翻页。沿用原分页和进度保存逻辑。

核实发现：0.2 只把阅读视图移入 Terminal 容器，没有显式排序，不能凭视图同时可见断言 Terminal 在左。0.3 显式调整原生终端的左右位置。集成测试连续切换右阅读 → 左阅读 → 右阅读，并读取实际 `views.log`，确认原生视图模型记录了 3 次 Terminal 与 Reader 交换，测试输出 `NATIVE LAYOUT PASS`。终端对象及 Shell 进程保留。

设置页验证包含：跟随字号时隐藏自定义字号输入、字号与行高实时预览、左右预览、保存确认、非法字号阻止提交、恢复默认、保存并继续阅读、隐藏清屏，以及 300px 宽页面无横向溢出。导入按钮仅在书架出现。预览截图为 `.test-data/screenshots/reader-v040.png`、`settings-v040.png`、`statistics-v040.png` 和 `library-sidebar.png`。原生窗口工具绑定问题仍存在，未做左右宽度的像素级对照；可用原生分隔条调整。

新增分页验证：按实际 DOM 字符矩形检查整章各页首末文字均在视口内，相邻页绝对范围连续且覆盖整章；包含中文、emoji 和跨 16K 测量块。验证滚轮和 PageDown 无翻页、Left/Right 翻页、前后章节按钮、章节边界回翻、目录跳转、动态页码、缩窄后仍包含原字符锚点，且被动重排不改写阅读进度。正文 DOM 保持当前测量块，未一次渲染整本书。

新增记录验证：多次会话按同书同日合并，不同书与日期分开；原始会话数量及有效时长总和不变。跨日会话没有逐日位置快照时只显示日期、时长，不推算不存在的每日进度。

## 性能样本

使用 `npx tsx scripts/benchmark.ts` 在本机测得：

| 样本 | 结果 |
| --- | --- |
| 合成中文 TXT | 10,485,670 字节，225 个正文块 |
| 副本、哈希、解析、缓存和书架提交 | 142 ms |
| 已导入正文缓存读取与解析 | 45 ms |

这是单次合成样本的数据路径测量，不代表所有 EPUB、所有机器，也不包含 VS Code 完整绘制耗时。隐藏的 DOM 清屏和集成行为已验证，200 ms 端到端视觉响应目标尚未进行精密测量。

## 待人工复核与范围限制

- 原生桌面自动化在便携版窗口绑定时返回 `window id … no longer belongs to Microsoft.VisualStudioCode; current owner is Microsoft.VisualStudioCode`，刷新后重试仍失败。没有以该工具的结果声称完成原生实际按键验收；建议在日常 VS Code 的代码编辑器、真实终端和阅读正文各按一次隐藏键复核，尤其是已有自定义键位/终端设置的环境。
- 系统文件选择框由操作系统管理；若该框正在打开，需先完成选择或取消。插件隐藏可取消自己的编码、改名及模式选择输入框，并中止进行中的导入。
- 仅 Windows 桌面本地场景进入本次验收；macOS、Linux、浏览器版、Remote/WSL/SSH 与 Codespaces 未验证。
- EPUB 复杂图文、DRM、固定版式和其他电子书格式不在本版范围内。

## 安装包

项目根目录的 `local-reader-0.4.1.vsix` 可覆盖升级安装。运行时文件仅包含扩展入口包、Webview JS/CSS、图标、说明及许可证，不包含测试书籍、测试配置、测试脚本、开发依赖或源码映射。

安装入口：VS Code 扩展视图右上角 `…` → “从 VSIX 安装”。首次使用点击左侧书本图标，在书架导入书籍。
